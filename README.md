# Aquifer — The Watershed Council

Англоязычная браузерная игра для 2–5 игроков. У каждого свой экран и рука. Уровень подземных вод, HP водоносного горизонта, события и сооружения общие.

## Обновление существующего сервера

Перенесите содержимое архива в корень репозитория `Serious-Game_MAR`, поверх текущих файлов. Ветка, с которой уже собирается сервер, должна содержать новые `pact-worker.mjs` и папку `public/`. Папку `public/` нужно перенести целиком.

| Настройка | Значение |
| --- | --- |
| Node.js | 24.x |
| Build Command | `npm run build` |
| Start Command | `npm start` |
| `PORT`, `HOST` | Оставьте настройки действующего сервера |
| `DB_PATH` | Укажите прежний файл SQLite на постоянном диске, если он настроен |

Обе версии игры используют существующую таблицу `rooms`. Миграция схемы не требуется. Новая игра открывается по главному адресу сервера. Старые ссылки с `?room=КОД` перенаправляются на `/legacy`, пока соответствующая комната есть в текущей базе. Если сервер заменяет локальный диск при перезапуске, комнаты сохраняются только при использовании постоянного диска.

## Как сыграть

1. Откройте адрес сервера, введите имя и создайте комнату. Выберите бассейн и число игроков.
2. Скопируйте приглашение. Другие игроки открывают ссылку или вводят код комнаты.
3. Каждый выбирает свободный класс. Владелец комнаты нажимает **Start game**.
4. Перетаскивайте карты из руки на стол. Клик по карте открывает описание и кнопку **Play card**.
5. Активный игрок бросает кубик и открывает способ ответа. Остальные могут применить свои карты, использовать подходящее сооружение или внести ресурсы. В окне ответа каждый управляет своим вкладом.
6. После каждого полного раунда игра проверяет **Basin Pact**. Для победы нужны безопасный уровень воды, достаточно общих HP, личные запасы всех классов и помощь каждого в этом раунде.

Карты доступны до и после броска, пока событие открыто. Каждый получает **Green Grant**, а фермер — **Drip Irrigation**. На своём ходу можно переработать одну карту в 2 Cash. Карты соперников видны только по количеству. Браузер, в котором игрок занял место, восстанавливает его после обновления страницы.

## Запуск на своём компьютере

```sh
npm run build
npm start
```

Откройте `http://127.0.0.1:8787`. Для проверки нескольких игроков используйте разные профили браузера либо обычное и приватное окно. Для подключения других устройств в локальной сети задайте `HOST=0.0.0.0` и откройте адрес компьютера в этой сети. Команды не требуют внешних пакетов.
